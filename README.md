# 🏙️ Strange City

**Strange City** — это мистическая 3D-игра от первого лица, написанная на **Java** с использованием библиотеки **LWJGL 3**.

![Strange City Icon](src/main/resources/textures/icon.png)

## 🕹️ Особенности игры
* **Собственный 3D-движок:** Написан на чистом OpenGL без использования тяжелых сторонних движков.
* **Атмосфера:** Странный город с уникальной авторской графикой.
* **Физика:** Реализована система коллизий AABB и гравитация.
* **Управление:** Классическая схема WASD + обзор мышью.

## 📂 Структура проекта
Проект разделен на логические модули для удобства разработки:
* `core` — главный цикл игры и инициализация окна.
* `engine` — рендеринг, камера и обработка графики.
* `entities` — объекты мира (игрок, платформы).
* `input` — обработка клавиатуры и мыши.
* `phys` — физический движок и коллизии.
